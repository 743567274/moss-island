# 地图模块（2.3.0）

入口由 project.godot 的 farm/map_path 指定，默认 res://data/lakeside-map.json。MapDefinition 在启动时读取并校验，IllustratedCourtyard 组合模块。天气由原有 EnvironmentController 驱动，地图文件不保存天气或真实农场状态。修改配置后重新导出即可发布新环境。

| 模块 | 配置 | 用途 |
| --- | --- | --- |
| 画面 | background、companion、world_size | 无植物/田块的完整草地底图；陪伴图的透明度用于前景轮廓；世界尺寸 |
| 月夜 | night_background（可选） | 与白天构图对齐的月夜受光图层，依据时间与月光融合；更换地图时一并准备 |
| 菜地/果园 | grids.crops、grids.orchard | origin 为底图归一化坐标；basis_a/b 为手绘等距投影的两个边向量；spacing 为地块间距倍率 |
| 水域 | water.points、widths | 2–8 个归一化路径点及各点半宽，用于水流动画与水上涟漪 |
| 桥 | water.bridge_exclusion | 归一化矩形 minX/minY/maxX/maxY，桥面不受水流扭曲 |
| 灯光 | lights | 最多 4 盏；id、position、radius、energy；lantern=true 增加暖色灯芯，否则只有光晕 |

方形田块采用同一份局部坐标生成网格、植物落点和命中区域。a、b 等长是方形地面经过手绘视角投影后的菱形；投影平面上不要求直角。统一从 tile 中心定位树根，树冠命中仍可选择果树。保持 12 个菜地和 6 个果位及其数组顺序，已有存档的作物和成长不会因环境更新而换 ID。改变田块数量需要单独做存档迁移，当前不提供该能力。

更换背景时，应准备不带生长植物和旧田块的底图、对应透明前景轮廓，再调整网格原点、尺寸、河道和灯光。重新导出后天气、昼夜、选择、种植、成长和采收继续共用。当前是有限画布的配置模块，并未实现无限地图、地形编辑器或游戏内地图切换。

底图柳树的局部摆动遮罩仍对应当前图稿；换成其他构图时需要同步调整 reference_plate.gdshader 的柳树区域。水和灯的位置已由地图配置驱动。

2.4.0 的土块改为透明插画，源图已含等距投影，因此显示在投影后的包围矩形内，避免再次投影造成扭曲。普通与选中素材按有效 alpha 边界归一化；命中仍采用同一局部方格。月夜图层中的屋窗及亭灯有手绘照明，更换灯位时应同步修改月夜图层，配置光晕与植物表面暖光仍独立驱动。
