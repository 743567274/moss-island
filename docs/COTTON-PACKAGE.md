# 棉花作物包

程序旁 `crops/cotton/crop.json` 是完整配置，`states.png` 是用户提供的原始透明图集。两行分别有5和6个状态，按实际透明间隔划分区域，避免机械等分裁断枝叶；原图像素保持不变。`assets` 中每个状态的 `scale` 是唯一大小调整参数，1为原比例，0.8缩小，1.2放大。`region` 是图集取样区域，一般无需修改。运行时只生成当前所需状态的有限尺寸纹理，不长期驻留整幅原始大图。

## 参考时间

采用正常供水下160个真实日的日历参考，不加速，离线仍按真实时间结算。

温度系统启用后还需保持适宜温度，具体见 `PLANT-CONFIG.md`；温度不适可能暂停成长、萎蔫或造成死亡，因此实际成熟时间可能延后。

| 阶段 | 持续时间 | 播种后累计 | 素材 |
| --- | --- | --- | --- |
| 种子 | 7天 | 7天 | 种子／种子缺水死亡 |
| 幼苗 | 33天 | 40天 | 幼苗／幼苗缺水／幼苗死亡 |
| 半成熟·现蕾 | 23天 | 63天 | 半成熟／半成熟缺水／半成熟死亡 |
| 半成熟·花铃 | 55天 | 118天 | 同上 |
| 吐絮 | 42天 | 160天 | 成熟（尚未统一采收） |
| 成熟 | 等待采收 | 160天起 | 成熟 |
| 摘取 | 采收后7天 | 由采收时间计算 | 摘取 |
| 采后枯萎 | 等待清理 | 采收7天后 | 摘取后枯萎 |

参考[美国国家棉花委员会的生长资料](https://www.cotton.org/tech/ace/growth-and-development.cfm)：出苗4—9天，出苗至现蕾27—38天，现蕾至初花20—25天，开花至吐絮45—65天，播种至采收130—160天。配置取区间内参考值，棉花分批开花吐絮，首次吐絮和整田采收分开。实际生长受品种、积温、日照、土壤等影响；本程序不模拟积温，不能把160天视为所有地区的固定农艺周期。

## 浇水与枯萎

播种初始储水0mm，需要浇水；一次增加30mm，上限45mm，低于10mm显示缺水，低于2mm暂停成长。各阶段参考耗水分别为1.2、2、3、5.5、2.5、0mm/天。因此浇水间隔随阶段和降雨变化，不采用固定倒计时。

完全干土后，种子4天、幼苗7天、现蕾及花铃／吐絮10天连续断水会死亡；成熟阶段不因断水死亡。浇水会重置连续干土计时。没有专属缺水图的种子及吐絮／成熟阶段复用正常图，但水分规则仍生效。

储水容量、耗水量、死亡阈值、采后7天枯萎和每田4份产量均是可调模拟参数，不能仅从生长期资料推导为普适现实常数。摘取状态不产生二次收获，可随时铲除。每田默认1株；非种子阶段统一放大30%，种子大小不变。

## 导出与预览

仓库底部选择玉米或棉花，再点击“导出所选作物包”。棉花ZIP仅含 `crop.json` 和一份原始 `states.png`，不会重复打包11份图集。编辑配置后重启生效。

托盘的环境预览可选择棉花、田块、各生长阶段以及正常、缺水、干土断水推演、刚采收、采后枯萎。仅改变预览，不改真实种植数据。

本次更新沿用现有存档格式，保留玉米种植和库存，不重置农场。土地采用新的左右双状态透明图集；不改变田块位置、数量及桌面挂载方式。
