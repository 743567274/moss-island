# 灯光：自然衰减与独立擦除

地图中的独立灯光、灯具内每一个光源使用相同的照明和擦除规则，不依赖地图或素材名称。点光从实际锚点向周围自然衰减；不再把点光强制投影到素材底部，也不再自动禁止建筑、树木或画面上方受光。旧灯光保留已有颜色、亮度、开关和范围，加载后使用新规则，可能需要重新调整范围。

## 操作

1. 左侧选中灯光分类后显示“添加单独光源”。点击后创建独立地图光源，不自动绑定当前选中的素材。添加后默认发散光，在右侧切换为筒光或直射光，并调整位置、亮度、颜色和范围。旧绑定光源仍可正常编辑和跟随素材。
2. 在画布选中灯光，进入右侧操作区。灯具包含多个光源时，先在“光源”下拉框选择需要修改的一个。
3. 点击“擦除 / 恢复此光源照明”。窗口以夜景和其他光源的快照为背景，实时预览当前光源。
4. 用柔边橡皮擦除不该照亮的部分；用恢复画笔涂回受光区域。画笔大小以地图逻辑像素计，柔和度与强度可以独立调整。同一笔内重叠不反复叠加强度，多笔可以逐渐加深。
5. 可在窗口继续调整当前光源的亮度、范围、颜色，查看已擦除区域的效果；红色辅助标记可单独打开。支持撤销、重做以及 Ctrl+Z、Ctrl+Y / Ctrl+Shift+Z。取消或关闭窗口不修改项目。
6. 保存灯光后，再保存项目并应用到桌面。一次灯光保存可通过地图编辑器的撤销恢复。

## 保存与移动

每个光源分别保存 `paint_mask`（灰度 PNG）与 `paint_frame`（四个逻辑坐标）。白色完全受光，黑色排除当前光源，灰色按比例减少；其他光源不受影响。没有擦除记录时默认完全受光。PNG 按内容哈希保存到永久素材目录，旧文件不覆盖，供撤销和旧项目引用。

独立光源的擦除范围固定于地图；移动光源位置、改变范围不会移动擦除区域。灯具内的擦除范围保存为相对素材定位点的坐标，随素材平移和缩放；单独移动编号光源锚点时不移动擦除范围。再次编辑时映射回当前地图，保留已经移出画面的擦除记录，保存时合并到新的范围中。

已有绑定光源仍在 `lights` 数组中独立显示、锁定、编辑和删除，使用 `parent_key` 指向素材或田块。`position`、`radius`、`paint_frame` 保存相对父素材的坐标，预览与运行时解析为地图坐标。坐标控件和拖动画布始终操作地图中的实际位置。父素材与光源一起多选移动时，先更新父素材，再计算光源偏移，避免重复位移。删除父素材一并删除绑定光源，可整体撤销。素材透明度同时影响绑定光源强度。无需把普通素材改成灯具类型或补充夜间图；旧昼夜双贴图灯具与其编号锚点保持兼容。

## 渲染与限制

桌面和编辑预览共用光照衰减及遮罩采样函数。每四个光源一批，使用四张独立遮罩，不共享擦除结果；未限制光源总数。笔刷只在编辑时修改灰度图，运行时由着色器采样，没有逐像素 CPU 重绘。运行时遮罩限制到 768 像素最长边；编辑快照为 768×432，超出地图的合并遮罩最长边最多 2048 像素。

桌面灯光位于 CanvasLayer(10)，在全部 3D 素材绘制完成后，通过一次全屏 BackBufferCopy 获取完整场景，再进行所有光源批次的加亮。全局雾位于层 20，界面位于层 100。旧版空间着色器的屏幕采样只包含不透明几何，透明贴图本体尚未合成，可能把贴图背后的背景纹理加亮到本体上，形成假透底；新路径避免此差异。屏幕光照坐标由相机射线映射回地图，适配不同桌面比例。图片原有 Alpha 和用户设置的透明度保持原义。

引擎屏幕采样时机参考：https://docs.godotengine.org/en/stable/tutorials/shaders/screen-reading_shaders.html 。

擦除只减少程序计算的该光源照明，不修改基础图片、自发光灯芯或其他光源。原图中已经画出的门前光斑等固定亮部无法通过此橡皮擦消除，需要修改原图。仍为 2.5D 近似照明，不自动生成真实三维投影或遮挡。编辑器夜景底色与桌面环境受光仍有近似差异；局部光的衰减和擦除规则一致。

素材旋转时，灯具锚点、绑定灯光位置和照射方向一同旋转。擦除记录以父素材为旋转中心，运行时通过 `light_mask_transforms` 做逆变换采样；重新绘制保存时记录 `paint_angle`，使当前画面中的笔触与后续父素材旋转保持一致。重新编辑会按旋转后的区域取样并保留移出画面的记录。
