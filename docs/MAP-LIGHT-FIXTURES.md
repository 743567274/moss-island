# 灯具素材：昼夜双贴图与发光锚点

自然受光首版：开灯贴图的本体参与夜间环境着色，灯芯亮度单独保留。默认通过昼夜贴图的暖色亮度变化估计发光区域；可在右侧操作区打开“标记灯芯 / 自发光区域”修正，布局保存 `emission_mask`。当前光源从实际锚点自然衰减，不再统一排除建筑、树木或画面上方；使用独立柔边擦除记录控制受光范围，详见 LIGHT-PAINTING.md。仍为轻量近似，背景整图中未拆分的物体不能自动产生逐物体遮挡。

灯具是一个地图对象：白天贴图、夜间贴图、发光位置和光照参数一起保存、移动和缩放。适用于灯笼、灯泡、关灯/开灯的汽车等，不限制图片内容。

## 添加

1. 左侧选择“全部素材库”及“灯具 · 昼夜双贴图”，导入白天外观。
2. 在素材属性中上传夜间外观。两张贴图均为必填，画布像素尺寸必须相同，物体在图片内的位置也应保持一致。缺失或尺寸不符时不能保存或放置灯具。
3. 在图片预览中点击或拖动发光锚点，也可输入 0～1 的图片内坐标。此锚点不同于素材移动时的定位锚点。
4. 选择发散光、筒光或直射光，调整方向、筒光夹角、范围、亮度和颜色。方向 0° 向右、90° 向下。
5. 保存素材属性，再点击“添加选中素材到地图”。

可启用/禁用光源、仅夜间开灯或全天开灯，以及光照轻微闪动。仅夜间模式下白天显示白天图、夜间显示夜间图；运行时随昼夜参数平滑过渡。关闭光源时使用未点亮外观并停止照明；全天开灯时始终使用点亮外观。

夜间图保留其绘制好的灯芯、灯罩或车灯细节，不再把整辆车或整盏灯统一染成黄色。周围地面的光由实际锚点和光照参数独立计算。

## 修改地图上的灯具

单独选中一个未锁定灯具，并开启“灯光锚点”，地图画布上会出现带十字的青色圆形发光锚点。直接拖动它，只改变光源在贴图内的相对位置，贴图本身不移动，夜景照明实时跟随。锚点限制在图片范围内，允许放在透明区域。拖动锚点之外的贴图区域则移动整个灯具，发光锚点同步跟随；等比缩放也保持相对位置。一轮锚点拖动支持一次撤销或重做。多选、锁定或关闭锚点显示时不会误拖发光锚点。

从右侧图层选择一个未锁定灯具，点击“编辑灯具 · 昼夜贴图与发光锚点”。此处只更新当前地图对象，不修改素材库和其他实例。可以替换昼夜贴图、改变发光位置和灯光类型；支持撤销和重做。

打开夜景预览，外观与环境照明同步显示。移动或缩放整个灯具时，发光锚点和照射范围一起跟随。独立补光仍可使用原有内置灯光。不限制灯具内光源数量和地图光源总数；渲染按数量自动分批处理。

## 保存格式

原有 `texture` 为白天图，新增 `night_texture` 为夜间图，`sprite_aspect` 保存原始贴图宽高比。对象的 `fixture` 包含：

```json
{
  "anchor": [0.5, 0.5],
  "kind": "spot",
  "angle": 90,
  "aperture": 60,
  "range": 160,
  "energy": 0.65,
  "color": "ffb45c",
  "enabled": true,
  "night_only": true,
  "flicker": false
}
```

两张贴图均复制到永久地图素材目录；不会依赖原始下载路径。布局、复制项目与重新打开保留整套配置。旧版单贴图光源保持兼容；新建或升级灯具时须补齐两张图。每个灯具支持多个发光锚点：素材或实例编辑窗口中的光源下拉框切换当前光源，添加、复制、删除按钮管理列表。画布上单选灯具后显示所有编号锚点，可分别拖动。至少保留一个光源。旧单光源仍为第一个光源，附加光源存入 `fixture.sources` 数组，每项使用相同的参数结构（不再嵌套 sources）。所有光源关闭时显示白天关灯图；任一光源全天开启时始终显示开灯图，否则随昼夜切换。

灯光合成顺序：背景和可见素材先绘制，所有局部灯光再统一在前景叠加，最后绘制全局雾与雨雪。前四个与后续光源使用同一合成路径，不再被夜间贴图覆盖，也不在素材着色阶段重复叠加。重新应用布局时会重建并释放旧光照层，避免累积。此修复不等同于新增自发光区域标记。

发光锚点与地面投影现已分开计算：画布锚点保留图片内的二维位置，点光从锚点向周围照射，不再投影到素材底部。右侧增加“本体夜间亮度”，默认 0.55，范围 0.1～1.5，仅调整非自发光本体的夜间最低可见亮度，不提高灯芯亮度。编辑预览与运行时使用相同参数，随实例保存并支持撤销。

光源锚点不再限制在图片内部，允许负数与超过 1 的坐标；地图中拖动或在侧栏输入 X/Y。图片预览保留外围空间。每个光源独立设置“穿透所属贴图（不照亮本体）”：默认关闭，正常照亮所属贴图；开启后按所属贴图透明轮廓排除该光源的本体照明，其他光源不受影响，透明区域仍透光。该开关不清除贴图中烘焙的亮光或灯芯自发光。
