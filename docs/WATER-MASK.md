# 水面标记与水流

当前入口已改为地图顶部“水域标记”，或左侧“绘制 / 修改地图水域”。直接在地图预览中绘制不可见范围，水域不进入图层列表；纯色缩略图可点击显示辅助标记、双击编辑。详见 `MAP-CLASSIFIED-EDITOR.md`。下文为旧版素材局部遮罩的数据兼容说明；存在地图级标记时，以地图级范围为准。

## 标记素材

在地图编辑器的素材库选择图片 → 素材属性 → 类型选择“水域” → “标记水面”。

编辑窗口以蓝色显示水面，棋盘格表示原图透明区域。原始素材不会被改写。

- 透明水面图片：默认按原图透明轮廓初始化，透明部分不产生水面动态。
- 整景或带河岸、桥的图片：先清空标记，再用画笔涂出水面；用橡皮擦排除河岸、桥、石头、船和荷叶等静态部分。
- 矩形、椭圆：按下并拖动，松开填充。
- 多边形：依次点击顶点，按“完成多边形”或右键填充；画笔可继续补充，橡皮擦可挖空。
- 支持撤销最近20次绘制，或按透明轮廓重置。

水流方向0°向右、90°向下，右下角箭头显示方向；速度0～3，0表示停止流动；边缘柔化0～16个标记像素。

点击“保存水面标记”，随后点击“保存素材属性”。新放置的实例会带上这份标记与水流参数，已有实例不自动覆盖。

## 单独修改某一处水面

在右侧图层或画布中选择水域素材，点击“标记此处水面 / 水流参数”。修改只影响这个实例，其他位置和素材库默认参数保持不变。完成后保存项目并应用到桌面。

标记使用相对于素材图片的坐标，因此移动、等比缩放水面时会一起跟随。桥、船、荷叶也可以拆成独立图片，按图层放在水面上方。

## 桌面效果

只有标记内的水面产生水流位移，风速增强时波动更明显。标记外的河岸、桥等保留原像素位置。

雨天涟漪随时间重新选择位置和相位，只出现在标记水面内，并沿用屏幕下三分之二区域的限制。涟漪与水面在同一个材质内绘制，上方图层可以遮住它，不额外生成一批水面粒子。

仍需在素材/实例上启用水域动画。速度设为0只停止流动；关闭整个类型动画则停止水流与该材质内的水面涟漪。

## 存储

标记最长边512像素，保存为`user://maps/materials/water-<hash>.png`，按内容去重。配置中的`water`包含`mask`、`angle`、`speed`和`feather`。素材库和地图实例分别保存参数。

没有标记的旧水域继续使用透明轮廓。标记文件缺失时阻止应用项目；已加载项目中缺失的标记则停止该水域动画，避免错误地让整张含河岸的图片晃动。

复制或迁移项目时仍需携带共享`maps/materials`目录。本次只完成编译与打包，不运行功能或性能测试。
