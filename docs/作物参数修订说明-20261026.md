# 作物参数修订：仅 JSON

本轮只修改作物配置，不修改作物编辑器、生长执行程序、图片或地图。不调整已有种植记录的累计成长秒数、库存数量或健康状态；加载新配置后，后续成长按新参数执行。

| 作物 | 正常供水下参考周期 | 此次主要调整 |
|---|---:|---|
| 玉米 | 130天 | 定义为中熟籽粒用途参考；阶段7+18+25+25+55天，单株参考主要果穗1穗。不是甜玉米鲜食首次采收期。 |
| 棉花 | 160天 | 保留合理参考周期，提高花铃期平均耗水，补充播期与参考条件。 |
| 辣椒 | 150天 | 发芽14天、其后育苗42天；总周期保持150天。结果期耗水较高，成熟植株不再完全不耗水。 |
| 西红柿 | 150天 | 从播种起算，包含育苗，按一季集中采收目标设置；不声称等于首次采果日期。 |
| 烟叶 | 180天 | 含约60天育苗、120天田间阶段；成熟待收期间仍有少量耗水。 |
| 春小麦 | 120天 | 保持总周期，调高拔节、抽穗与灌浆期相对耗水。 |
| 冬小麦 | 250天 | 保持跨年周期与越冬阶段；调整播期说明、开花灌浆耗水。 |
| 玫瑰 | 120天 | 仅保留“已完成休眠解除处理的早花类种子”模板，不把120天宣传为全部玫瑰的真实首花周期。 |

所有作物播种时按湿润土壤起步，初始储水为各自容量的60%。这表示播前已做适度润土，不是新增自动浇水功能。没有给真实土壤统一规定60%含水率，也不应将游戏mm储水值当作土壤实测含水率。

现有播种温区、阶段适温与死亡等待规则保留；只靠JSON无法分离最适温度、危险温度和致死温度。干土死亡天数、枯萎等待及部分库存份数仍属于可调整的模拟参数，不声称具有统一生物学精度。

保留单次采收规则：番茄、辣椒等实际分批产出在游戏中合并。没有给配置添加一个不会执行的“真实多次采收”开关。冬小麦春化、土温与积温、玫瑰冷湿层积、授粉与多年生复花也不在此次参数修改范围内。

每个作物的JSON新增 `parameter_reference`，记录参考用途、起算条件、资料来源与这些限制。这些是说明元数据；实际执行的仍是 `stages`、`duration`、`watering`、`temperature`、`harvest`、`sowing` 等已有字段。

当前自定义玫瑰通过新版本包更新初始水量和文字说明，保留其12张图片、缩放、阶段专用温度及采后外观；旧版本和索引备份保留，不修改植物图片。

## 参考资料与数值性质

- [FAO：生长期、阶段与需水估计](https://www.fao.org/4/s2022e/s2022e07.htm)。生长期受品种、气候和播期影响；其四段水分管理阶段不能直接等同于程序的每一张视觉图片。本次具体阶段分配为参考范围内的建模选值，不是资料逐项给定的固定天数。
- [FAO：作物需水](https://www.fao.org/4/s2022e/s2022e02.htm)。配置的mm/日是分阶段日均参考，未加入实时蒸散计算；不能据此保证每个地区的实际浇水间隔一致。
- [伊利诺伊大学：玉米](https://extension.illinois.edu/gardening/corn)。主要果穗和第二果穗受生长条件影响，本次不再默认一株固定4穗。
- [Cotton SA：棉花技术资料](https://cottonsa.org.za/technical-information/)。160天可作为特定暖季条件的参考，不等于任意产区保证160天成熟。
- [俄克拉荷马州立大学：棉花灌溉](https://extension.okstate.edu/fact-sheets/understanding-cotton-irrigation-requirements-in-oklahoma)。实际耗水随阶段、土壤和环境改变。
- [ICAR烟草气候资料](https://nirca.icar.gov.in/farmers.php?page=soils-climate)。烟草需区分类型与产区，育苗与田间起算点不可混用。
- [爱荷华州立大学：玫瑰繁殖](https://yardandgarden.extension.iastate.edu/how-to/how-propagate-roses)。种子处理要求依物种而异；本次未伪造统一的层积和开花天数。

对应变更数值见同目录 `作物参数参考表-20261026.json`。未运行功能测试。
