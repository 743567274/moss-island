# 河岸柳树替换

用户提供的 `柳树.png` 原样保存为 `assets/illustrated/willow.png`。地图文件 `data/lakeside-map.json` 的 `willow` 节点配置素材路径、透明有效区域、根部位置、锚点、基础高度、整体 `scale`、风摆幅度和透明边缘清理参数。

旧柳树原本绘制在白天与夜晚背景中。本次使用内置 image_gen 分别补出无树的河流和草岸，保存为 `assets/illustrated/willow-clean-day.png`、`assets/illustrated/willow-clean-night.png`；原始背景没有覆盖。运行时仅从补图中提取旧树所在的小矩形，局部混合到原始背景，矩形外仍使用原图。补图提示词见 `docs/willow-edit-prompts.json`。

新柳树使用独立平面图层；原有水流扭曲不再作用于树体。树干、树根固定，只对绿色叶片区域施加分区、错相位的小幅风摆；摆幅随天气风速变化。树根附近添加轻柔接触阴影，树体保留原图水彩颜色，夜间仍参与月光与局部灯光着色。

纹理沿用运行时透明边缘清理和缓存。柳树最大边768像素，白天、夜晚的河岸补片只保留所需小区域，避免长期驻留两张新增全屏纹理。修改 `willow.scale` 可统一调整树的大小，根部位置不变。

本次只替换河岸环境树，不加入可种植果树，不改动农田、作物配置或存档。按用户要求，仅构建并重启，不运行测试。

## 第二版边缘与配色

原图在柳条之间仍有浅色纸底和白色轮廓，仅处理透明边界不足以去除。本次使用内置 image_gen 将内部空隙、根部和枝叶边缘重新处理成透明，并参照原河岸背景调整为较柔和的灰绿、橄榄绿，减少亮黄。新素材另存为 `assets/illustrated/willow-v2.png`，原图保留。

新素材设置 `edge_cleanup.alpha_floor=0.125`：清除接近完全透明的提取残留，再补全边缘颜色和生成mipmap，避免残留RGB在缩小采样时染色。此参数只对柳树启用，其他素材保持原配置。`willow.day_exposure=0.92` 对白天作轻微亮度匹配，不改变其他植物。完整提示词记录在 `docs/willow-v2-prompt.json`。

同时取消精灵UV向内钳制，图像外部明确透明，避免顶部或边缘像素被拉成矩形色块。树根固定、叶片随风的逻辑保留。
