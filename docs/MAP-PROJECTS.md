# 场景项目与空白地图

2026-10-22：项目管理首版。已接入现有桌面设置和托盘菜单；按约定跳过功能与性能测试。

## 打开与创建

桌面空白处右键 → 苔屿设置 → 场景项目，或托盘右键 → 场景项目 · 地图编辑器。Windows 11可能需要进入“显示更多选项”。

现在首先显示项目列表，包括缩略图、名称、田块数量、素材数量、修改时间和正在桌面使用的标记。

- 新建空白项目：输入名称后进入编辑。初始没有田块、树、房屋、河流或灯光，只有可调整的底色。
- 编辑：双击项目或点击编辑，继续上次保存的内容。
- 保存项目：保存布局与缩略图，尚不改变当前桌面。
- 应用到桌面：保存当前农场，再切换场景和对应的种植、库存。
- 复制：只复制已保存的布景，生成新的项目及田块编号，不复制作物、库存和收获次数。
- 删除：先切换其他项目，再删除当前选中的项目。目录移入`maps/deleted-projects`，共享素材保留。
- 关闭编辑窗口或点击返回项目列表：未保存时提示丢弃修改，返回项目列表。

原有场景迁移为“湖畔庭院 · 原有布景”，保留原种植记录及仓库。迁移只执行一次；后续删除这个示例不会在下次启动自动重新生成。

## 从零拼出场景

1. 导入地表、草地、水面、树木、房屋、云层等透明图片，在素材属性中设置类型。
2. 选中素材，添加到地图，调整位置与等比大小。素材库在所有项目之间共用。
3. 在右侧统一图层中拖动素材调整上下遮挡，列表上方覆盖下方；土地与其他可见素材按相同规则自由排序。
4. 土地绑定选项默认为“新增一块田”，也可以替换某块已有田的外观。
5. 田块可从0块添加到最多128块，支持圆形、方形投影、透明轮廓、自动提亮或专用选中贴图、独立种植锚点。
6. 从对象属性移除空田；有作物时须先在桌面完成收获和铲除。田块重排不会让作物串到其他田块。
7. 保存并应用项目。新建项目不会自动清空或替换正在桌面使用的项目。

1920×1080仍只是设计坐标。壁纸沿用实际显示器分辨率与覆盖方式。

新空白项目不依赖示例的整张插画。示例仍有部分房屋、桥等画在背景里，无法单独拆开拖动；这些限制不会把预制建筑带进新项目。

## 右侧图层面板

右侧上半部分为图层列表，下半部分为选中对象属性，分隔条可以拖动调整高度。

- 统一图层：土地、云雾图片、水面贴图、地表、树、建筑和装饰统一列出，拖动到目标行的上半部/下半部即可放到其上方/下方；绿色横线提示插入位置。也可使用上移、下移、置顶、置底。
- 田块与其他素材自由排序。作物、接触阴影和种植记录跟随原田块，不通过重排存档数组实现图层移动。不可见水域标记不在图层中。
- 灯光：选中后编辑位置、范围、角度等；光源参与照明，不作为图片参与遮挡排序。

背景/底色固定为最底层。示例中直接画在底图里的房屋、桥不能分别拖动换层。

点击画布会选中对应图层；左侧查看当前地图时也定位到对应素材分类。重叠位置优先选择最上层可见对象。自定义素材的透明部分不会遮挡下面对象的选择。

调整顺序后可以撤销、重做；保存项目后再次打开仍保留。点击应用到桌面后，壁纸使用与编辑画布相同的图层顺序。土地不再固定置顶。

布局新增`layer_order`字段，保存稳定对象编号；旧项目没有此字段时使用默认分组顺序，无须清空地图或作物。

## 灯光属性

左侧直接添加发散、筒光或直射光，不需要上传图片。项目最多共用4个光源，包括旧项目原有灯光与以前导入的灯光素材。

| 类型 | 表现 | 可调参数 |
| --- | --- | --- |
| 发散光 | 以位置为中心，柔和向四周衰减 | 位置、范围、亮度、颜色 |
| 筒光/聚光 | 向指定方向照射的柔和扇形光束 | 位置、方向角、夹角、范围、亮度、颜色 |
| 直射光 | 场景范围内带方向的明暗渐变 | 方向角、亮度、颜色 |

三类灯均支持启用/关闭、仅夜间开启或全天开启，以及轻微闪动。方向角0°朝右、90°朝下；只有筒光可编辑夹角，只有发散和筒光使用局部范围。

编辑画布显示锚点、范围和方向；完整光照以应用后的桌面为准。灯光参数共同作用于背景、土地、作物和独立素材。

此处为轻量二维着色效果：筒光是二维方向遮罩，直射光是二维方向明暗渐变；没有新增实时三维阴影或自动的建筑遮挡计算。

## 存储与兼容

```text
maps/
  active-project.json              正在桌面使用的项目编号
  active-layout.json               已应用的布局快照，保存项目不会替换此快照
  project-migration.json           原布景迁移标记
  materials.json                  共享素材库属性
  materials/<hash>.png            共享素材原件
  projects/<project-id>/
    project.json                  项目名称、布局、修改时间
    draft.json                    保存的编辑内容
    preview.png                   场景缩略图
    farm.json                     独立种植存档
    farm-collection.json          独立库存
  deleted-projects/               被删除的项目目录
```

示例项目为兼容旧版本继续使用用户数据目录根部的`farm.json`与`farm-collection.json`，新项目使用各自目录下的文件。

种植存档保留现有校验和及多份备份。每株作物额外绑定稳定田块编号，界面序号仅用于显示和操作；播种、收获、铲除保留这个编号。

项目布局使用版本2；旧单地图布局在首次启动时迁移。JSON替换前保留`.previous`文件。恢复已删除项目时，把完整项目文件夹移回`projects`并恢复原项目编号的文件夹名称。

未在桌面使用的项目保留自己的最后种植时间；下次应用时按既有真实时间规则结算。不为离线期间虚构温度或降雨。

## 当前边界

素材图片仍需自行准备；不会把一张整景插画自动拆成房屋、河流和树。分类素材、统一图层、地图级不可见水域绘制已加入，详见 `MAP-CLASSIFIED-EDITOR.md`。地图包 ZIP 导入导出尚未加入。
