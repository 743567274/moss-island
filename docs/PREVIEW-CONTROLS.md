# 风速与作物阶段预览

从托盘打开“天气与作物预览”。面板新增0—55km/h风速滑条，0.5km/h一级；55km/h对应当前视觉风力上限。调节后立即预览，联动作物、柳树、河流波纹及雨雪的风偏。0风速停止种植植物与柳树的风摆，河流仍有基础流水动态。风向沿用当前天气信息，没有数据时采用默认方向。

作物预览步骤：

1. 选择作物和预览田块，包含玉米、棉花、春小麦、冬小麦、辣椒、西红柿、烟叶。
2. 通过“生长阶段”直接跳转到某阶段起点，绿色成长进度条随之更新。
3. 拖动绿色进度条，可查看从播种0%到成熟100%的任意成长时刻。标签显示当前阶段、阶段内完成度、总成长百分比以及参考生长天数；拖动跨过阶段边界时，阶段名称和贴图自动切换。
4. 水分与状态选项仍提供正常供水、缺水外观、干土断水推演、刚采收、采后枯萎、温度不适推演。推演以进度条选定的时刻作为初始进度，结果另显示在下方；某些阶段共用同一张素材时，图像可能不变，但阶段名称、时间和参数仍按配置切换。

“真实存档”选项关闭作物预览。点击“恢复真实画面”或关闭预览窗口，恢复真实时间、天气、风速与实际种植，风速控件同步回当前天气值。整个面板的内容可滚动，避免更多控件超出屏幕。

新增风速保存在临时环境预览字典，传入既有环境控制器；不改写天气缓存、配置、系统时间。作物阶段继续使用独立模拟状态与场景外观覆盖，不把预览植株写入真实农田或库存。

按用户要求，本次只构建并重启程序，没有运行功能测试或性能测试。

风摆可见度修正后，作物改为根部固定、上部弯曲，柳树加强垂叶运动。可拖动风速滑条对比0、20与55km/h，种子默认不摆，正常植株与柳树叶片应有明显的风力响应差别。仍需用户在桌面确认实际观感。
