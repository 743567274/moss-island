# 地图氛围与素材变换

云层平移速度关联天气风速（包含测试风速）：归一化无风为 0.25 倍速度，最大风速为 4 倍，基准一轮 180 秒。速度平滑过渡，位移通过累计时间推进，改变风速不会重算位置或突然跳动。水平行程保持不变。

云层动画现在保持图片形状，沿水平方向缓慢往返，约 180 秒完成一轮，逻辑行程约 480 像素，端点平滑转向；不再随风向上下摆动。为着色器平移增加了裁剪余量，避免仍在画面内的云因原始包围盒移出而提前消失。

雾天由独立雾层统一提供：远处相对浓，近处存在非均匀的雾团、薄雾和通透区域，多个尺度的密度缓慢漂移。背景不再额外叠一层均匀灰雾。透明度和速度继续沿用项目设置，速度 0 时密度图案静止。这是按画面远近设计的 2.5D 近似，不是真实体积雾或逐物体深度计算。

土地与环境素材使用同一个可排序图层列表，作物跟随所在土地的顺序。天气是独立覆盖层：全局雾气覆盖场景、田地和作物，雨雪在雾气上方，操作界面保持最上层。用户添加的云雾图片仍可自由排序。

项目左栏可调整雾气透明度（0～1）和飘动速度（0～3）。天气仍决定雾量：透明度不会把晴天强制变成雾天。背景保留远景空气透视，独立雾层提供近景与低空雾带。

选中素材或田块后，右侧可以调整：

- 素材透明度：0 为完全透明，1 为不透明；田块透明度也作用于其中的作物。
- 阴影强度：0～0.8，0 关闭阴影。
- 阴影范围：0.2～3，等比改变根部柔和接触阴影范围。接触阴影用于融合素材与地面，不是实时投射的三维阴影。

这些属性保存到各项目的布局记录中：`opacity`、`shadow_strength`、`shadow_scale`。雾气设置保存为项目字段 `fog_opacity`、`fog_speed`；旧项目省略时使用默认值。

画布内图片按地图逻辑边界裁剪；越界部分保留原素材内容和坐标，拖回地图后会重新显示。导入文件不被裁切。选中对象的四角显示缩放控制点，拖动时保持原始宽高比与锚点；右侧仍可输入缩放比例。田块和作物一同缩放，灯光继续通过自身范围属性调整。

保存项目只保存布局；点击“应用到桌面”后，桌面加载新的透明度、阴影和雾气设置。撤销与重做同时记录这些编辑。

素材操作区支持阴影距离（-240～240 逻辑像素）及方向（0°向右，90°向下）。负距离沿所选方向反向偏移。这两个参数改变接触阴影与素材根部的相对位置，透明度和范围仍独立设置；编辑预览与桌面随项目保存。田地的作物接触阴影受所在田块范围限制。

雾边缘柔化：密度插值改为更平滑的五次插值，降低高频细节并拓宽薄雾到浓雾的渐变区，按屏幕导数增加抗锯齿。云层、雾气图片单独保留低透明度边缘，不再沿用实体素材的 0.3 透明度截断，并在图片边界做渐隐。

全局雾使用 CanvasLayer(20) 下的全屏 ColorRect，在所有 3D 图层和屏幕采样灯光完成后统一绘制，HUD 明确使用 CanvasLayer(100)。雨雪位于 3D 场景中，也会被雾衰减。切换项目时同步隐藏旧雾层，避免资源交接期间重复叠加。

雾密度使用一张 256×256 无缝平滑噪声纹理（固定种子），线性过滤后叠加低频漂移；移除逐片元 sin/fract 哈希和 fwidth 驱动阈值。使用 SCREEN_UV 定位，不依赖素材 UV。纹理仅生成一次，不逐帧在 CPU 重建。编译检查不能代替目标桌面的视觉验证。

层级参考：https://docs.godotengine.org/en/stable/classes/class_canvaslayer.html 。负层决定相对其他 CanvasLayer 的顺序；BG_COLOR 场景仍先于画布绘制，不能仅凭层编号判定旧问题来源。
