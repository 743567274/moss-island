# 玉米统一图集

玉米改用用户提供的 `玉米.png`，原样保存为程序旁 `crops/corn/states.png`。配置为同目录 `crop.json`，导出ZIP只包含配置与这一张图集，不再打包旧的独立阶段图片。

上排从左到右：种子、种子死亡、幼苗、幼苗缺水、幼苗死亡。

下排从左到右：中期正常植株、中期缺水、中期死亡、成熟、收获图标、采后枯株。

新图集只有一种中期正常外观，因此原有“半成熟、长大、结果”三个计时阶段共用下排第一张图；三段的时长、耗水、温度与收获规则保持不变。仓库图标使用下排第五张，收获后仍按原规则直接显示最后一张枯株。旧存档中的植株自动显示对应新素材，不需要重新播种。

## 大小

各素材按图集中原有的相对像素尺寸呈现，统一使用 `render.atlas_reference_height`（当前1.4）和 `render.atlas_reference_region_height` 作为渲染基准；后者由图集最大的植株区域计算，不需手动修改。采用这一方式时，视觉高度以图集比例为准，原阶段 `height` 不再分别拉伸图集中的植株。

单独调某个素材，仍只修改对应 `assets.<状态>.scale`：1为默认，0.8缩小，1.2放大，没有横纵独立缩放。`adult`、`fruiting` 等别名可分别调整scale，但仍引用同一图集区域。

`render.edge_cleanup` 沿用棉花的透明边缘处理。原始PNG不修改；运行时生成缓存纹理。后续需要重新接入这张图集，可运行 `dev/update_corn_atlas.py`，它优先读取程序旁现有配置并保留生长及温度参数。
