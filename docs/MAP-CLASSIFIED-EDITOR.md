# 分类素材与统一地图图层

地图编辑器仅管理环境，作物仍使用独立的作物配置、贴图和种植存档。

## 素材入口

左侧统一显示素材，按分类选择土地、地表、草丛、环境树木、云层、雾气、水面贴图、建筑、装饰、背景或灯光分类。“添加选中素材到地图”是独立按钮。

- 当前地图列出实际使用的独立素材和使用数量。点击条目定位到一个使用该素材的地图对象；右侧图层可选择每个实例。
- 选中田块后，右侧土地操作区并排显示该田块实际使用的普通态、选中态贴图，每张图下方有“更换图片”。预览随当前田块和更换结果更新，不跟随左侧素材库的高亮条目。左侧不再显示这组预览。自定义选中图、内置图集选中态和自动提亮都可预览，土地不与作物贴图混合。
- 左侧放置按钮按资源显示为“新增田块”“新增到地图”或“定位地图对象”。“编辑素材默认值”对可编辑的自定义素材显示，修改以后新增对象的默认设置；当前地图实例的修改位于右侧。“添加单独光源”仅在灯光分类显示，创建独立地图光源。
- 素材库保留各项目共享的导入图片；在某个分类导入时，先赋予该类型，再打开素材属性进行调整。
- “导入图片素材”支持文件窗口多选，多张图片统一进入当前分类，不连续弹出属性窗口；单张导入保留原属性编辑流程。普通态、选中态、灯具昼夜图等一对一替换窗口仍使用单选。导入失败的条目单独报告。
- 素材库可用Ctrl/Shift多选，“新增所选N个素材”批量放置，普通素材和田块略微错开放置并一起选中，整次添加可用一次Ctrl+Z撤销。容量不足或灯具配置未完成的条目会跳过并提示。背景仍按专用底图规则居中铺满。
- 内置耕地在土地分类中可直接使用，无需重新导入。空白地图也可放置。
- 素材列表下不再显示土地绑定下拉框。“添加选中素材到地图”对土地只新增田块；修改现有田块需要先在画布选中它，再从右侧“从素材库替换此田块外观”选择土地素材，或分别替换普通态、选中态贴图。替换保留位置、缩放和种植记录。
- 右键自定义素材，可选择“从素材库删除”。只移除素材库条目，保留被项目、草稿或撤销记录引用的图片文件和地图实例。写入前保留库文件的 `.previous` 备份；内置耕地不能删除。移除地图实例须选中后在右侧操作。
- 示例背景整图中尚未拆分的房屋、桥等仍作为一张背景展示，不会伪装成可独立编辑的素材。

类型决定默认行为：地表、建筑、装饰和背景静止；草丛、环境树木随风；云雾素材缓慢漂移；水面贴图在标记范围内流动。可关闭类型动画。灯光继续使用独立的亮度、方向与范围参数。

背景类型为专用底图：默认居中、保持图片比例铺满1920×1080逻辑画布，超出部分裁切，不重复平铺或拉伸。编辑器和桌面共用适配计算，已有背景对象也按此规则显示；旧高度、位置和缩放记录不再影响背景。素材库隐藏背景的高度和动画设置，地图操作区隐藏位置、缩放及接触阴影。背景固定在全部普通图层下方，不参与拖动、缩放、方向键微调或Alt拖动复制；仍可从图层列表双击编辑透明度或移除。画布命中检测跳过背景，保留空白处框选。局部远山、建筑等需要自由摆放的图片应选择装饰或相应普通类型。存在多个背景时保留它们在底部的相对顺序。原有示例插画和项目底色继续位于所有导入图层下方。

## 图层

右侧只有一个统一图层列表，列表上方覆盖下方。土地与环境素材可互相拖动调整顺序，土地不再强制置顶。每块土地中的作物跟随土地的顺序。灯光也列在同一面板中供选择，其照射参数不参与图片排序；背景整图固定底层。

图层单击只选中并同步画布选框，双击（或选中后 Enter）进入该图层操作区。“移除选中对象”位于“返回图层列表”正下方。锁定对象可以在列表查看，但禁止移动、复制和移除。

快捷操作：Alt 拖动选中对象复制，移动超过5个画布像素后才生成副本，单纯点击不复制；多选时复制全部未锁定对象。副本深复制贴图引用、外观、阴影、动画、灯具设置、擦除记录等配置，使用新对象 ID，并放到原图层上方。复制父素材时同时复制其绑定光源；父素材和灯光一起选中不会重复复制或叠加位移。整次复制及拖动共用一次撤销快照。田块只复制地图外观与布局，不复制种植存档。内置柳树复制为普通环境树木素材，不复制原背景里的清理补丁。

方向键移动1个地图逻辑像素，Shift+方向键移动10像素，支持多选一起微调。Ctrl+Z撤销，Ctrl+Y或Ctrl+Shift+Z重做；参数输入框、下拉框和数值控件保留自身键盘操作，不拦截文本编辑。旧的 Alt 强制框选改为空白处拖动框选。

Del固定移除地图当前选中的图层，支持多选和一次撤销，不再根据素材库焦点删除库条目。素材列表通过“删除所选素材”按钮批量移除库条目，保留图片文件和地图实例。地图删除跳过锁定对象、内置底图、内置柳树及仍种着作物的田块，删除父素材时一并删除其绑定光源。编辑文字、数字、下拉框时保留控件自己的按键行为，不触发地图删除。

雨雪和全局天气雾仍由天气系统管理。用户添加的云雾图片属于可自由排序的环境素材。

## 多选与编辑锁定

在画布空白处按住左键拖动，框选与选框相交的未锁定对象；地图铺满素材没有空白时，可按住 Alt 从任意位置开始框选。Shift / Ctrl 点击可增加或移除单个对象，也可按住修饰键框选追加对象。拖动任何一个已选对象即可整体移动，相互间距保持不变。一次拖动对应一次撤销，组内锚点共同受地图边界限制。多选时只提供整体移动和批量锁定；缩放与详细参数请单独选中对象后修改。

右侧图层支持 Shift / Ctrl 多选。列表明确标注“可编辑 / 锁定”，下方按钮锁定或解锁所选图层。锁定对象在画布点选、框选和缩放中会被跳过，不能直接修改参数、删除、拖动排序或替换其土地外观；仍可从图层列表选择以解锁。

锁定状态以对象字段 `editor_locked` 保存到项目，支持撤销与重做。它只供编辑器使用，不隐藏对象、不停止桌面动画、不禁止农场种植操作。旧地图未包含该字段时默认未锁定。

## 夜景光照预览

夜景预览增加动态光照层，使用与桌面相同的灯光衰减、方向与夹角计算。拖动光源或调整范围、亮度、颜色、启用状态时，预览光照同步刷新。关闭“灯光锚点”仅隐藏编辑辅助标记，不关闭真实光照。点光、筒光和直射光均支持预览；仅夜间开启的光源在白天预览中关闭。

底图自带的灯笼亮面等绘画细节属于图片内容，不能通过移动独立光源消除；动态光照与图片自身的高光分开处理。风、水和天气动画仍以应用后的桌面为准。

## 不可见水域标记

顶部“水域标记”或左侧“绘制 / 修改地图水域”打开独立水域编辑窗口，对照当前地图描画。画笔、橡皮擦、矩形、椭圆、多边形及撤销均可使用，工具显示选中态，画笔圈显示当前范围。

水域不是图片对象，不进入图层列表，不改变水面颜色，也不会在空白地图上生成蓝色河流。它只控制哪些地图位置允许水流、波纹和雨天涟漪。实际可见水面来自背景、地表或水面贴图。树、建筑和作物保持自身动画，不因位于水域上方而按水面晃动。

左侧预览只显示透明底的蓝色水域轮廓。单击预览可切换地图辅助标记显示，双击或点击编辑按钮可再次修改。辅助蓝色永远不会显示到桌面。新建空白地图从空标记开始；旧示例第一次编辑时从原河道初始化。

地图布局的 `water_region` 保存 `mask`、`angle`、`speed`、`feather`，标记 PNG 按内容哈希保存到用户地图素材目录。形状允许多个不连通区域，统一使用该地图的流动方向与速度。保存项目、撤销、重做、复制项目和重新打开均保留该标记。共享素材原件不被修改。

有地图级标记时，它覆盖旧版水面贴图的局部遮罩配置；未编辑过地图水域的旧项目继续使用原效果。雨天涟漪在地图下三分之二的水域内随机出现。保存项目后点击“应用到桌面”更新运行效果。

## 素材操作区

未选择对象时，右侧显示统一图层列表；选中素材后，列表隐藏，整列显示该素材操作区。“返回图层列表”可保留画布选中对象并回到列表，选择其他图层后再次进入操作区。锁定状态可在两种界面中切换。多选时提供锁定与整体移动提示。

素材类型在分类导入时固定，地图实例与素材属性中不再提供类型切换。土地操作区提供普通态、选中态贴图替换、自动提亮、轮廓和亮度设置；内置土地修改后转为当前地图独立资源。灯具操作区直接提供光源选择、添加、复制、删除、光照类型、方向、范围、亮度、颜色及开关，另可分别替换昼夜贴图。操作影响当前实例，支持撤销、保存与重新打开。

图层选中态使用浅蓝底与深色文字，锁定图层的灰色文字在选中背景上也保持可辨识。

图层操作区新增“旋转角度（顺时针）”，范围-360～360°，对象字段为 `rotation_degrees`，默认0。支持环境素材、柳树与田块（连同其中作物）绕定位锚点旋转；背景保持铺满，不显示旋转项；独立光源仍用原光照方向设置。编辑预览使用带UV插值的多边形裁剪，旋转后图片仍只显示在地图内；点击、选框和缩放控制点按旋转后的几何位置计算。桌面渲染使用相同方向，光源锚点、绑定光源位置、方向及擦除记录随素材旋转。旧记录缺少角度时按0处理。

单选未锁定素材后，选框外显示圆形箭头旋转手柄；拖动围绕素材定位点旋转，Shift以15°吸附。靠近画布边缘时手柄移到画布可操作范围内，避免移出画面无法点击。拖动时显示角度，整次拖动可一次撤销。右侧提供左转90°、右转90°、归零和精确角度输入；背景和独立光源不显示这些素材旋转操作。切换素材或从列表进入编辑时，操作区回到顶部。


素材入口已统一：取消本地图/全局来源切换，按类型合并导入素材与地图已用素材，同 ID 只显示一次。地图对象通过右侧图层列表选择和编辑。保留素材导入、批量新增、默认属性与条目删除；不删除既有图片或项目引用。

导入的背景图片图层支持与其他素材交叉排序，编辑器与桌面均遵循保存的 layer_order。背景保持自动铺满、不允许平移缩放。未设置顺序时默认置底；项目固有底色/未拆分原画仍为固定基底。

背景/底色层现已参与统一排序，默认锁定，点击左侧锁图标可解锁再拖动。锁定状态 background_locked 与层级随项目保存；旧项目缺省锁定且维持原有底层显示。背景仍自动铺满，不参与画布平移缩放。此规则替代先前固定基底的说明。

土地桌面着色不再将原插画背景颜色混入田块边缘。旧实现会在移动田块、换背景后采样到无关区域，产生编辑器中不存在的灰色边带。保留贴图自身透明轮廓、选中提亮和作物接触阴影。
