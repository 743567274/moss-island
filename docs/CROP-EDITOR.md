# 作物编辑器

入口：托盘“作物编辑器 · 新增与编辑植物”，或设置中的同名入口。打开后是带 Logo 的植物列表，可新增作物、果树，双击编辑，或删除。编辑保存后即时刷新播种按钮和场景作物外观，不要求重启。

## 图片与类型

作物12个标准状态：seed、seed_dry、seed_dead、sprout、sprout_dry、sprout_dead、half、half_dry、half_dead、mature、harvested、withered。正常成长阶段为种子、幼苗、半成熟、成熟；缺水和死亡是分支，死亡终止，缺水可通过浇水恢复。残株同时用于成熟未摘取衰败和采后枯萎。

果树12阶段：dormant、budbreak、sprouting、leafy、buds、flowering、fruit_set、young_fruit、swelling、mature、harvested、leaf_fall。种下即是树形，成熟可采摘，采后进入采摘外观，再落叶、休眠并循环；未采摘到期直接进入落叶，不凭空发放收获。低温进入休眠的区间由 dormancy_min_c / dormancy_max_c 控制，只在有有效温度观测时使用。极端温度仍按适温规则累计伤害。

阶段里的施肥、授粉、疏果和品质目前仅表示视觉/生长阶段，不会产生尚未实现的玩法操作。默认时间为可调模板，不自动推断具体物种的农艺周期。

每种植物必须补齐12张状态图，也可导入从左至右、从上至下排列的6×2图集。旧配置会尽量映射原有图片，缺失的状态需要用户补充。每张图单独调整 scale，预览随缩放更新；Logo可上传，未上传时复用成熟图。

保存后的状态图片全部为512×512透明PNG，使用共同缩放基准并按底部对齐，保留原来状态间的相对尺寸。缩放参数仅影响显示，不改变文件画布尺寸。已经规范化的图片再次保存时不重复缩小。Logo独立保存，不要求与状态图片同尺寸。

## 参数

状态页调整正常成长阶段/果树各阶段的真实日数、耗水、干土死亡时间和阶段适温。作物缺水、死亡、采收状态不作为12个连续成长阶段推进，相关等待时间由正常阶段死亡阈值及收获设置控制。

常用参数页提供全局适温、播种适温、不适温死亡等待与成长系数，土壤水容量、初始水量、浇水量、预警和成长阈值、降雨吸收，以及产量、成熟未摘取枯萎、采后枯萎等待和摇曳幅度。阶段适温优先于全局适温；在对应阶段卡片修改。

全部参数页提供JSON，包含温度、水分、收获、渲染、播种季节、说明等其他资料；保存时进行配置校验。编号和类型在新建时选择，已有植物固定，防止存档串用。

## 数据与保护

用户配置保存在 user://crop-editor/index.json，植物包保存在 packages/<id>/<版本>/。索引原子替换并保留上一版，图片复制到永久包内，启动后不再依赖下载路径。编辑会覆盖同编号植物的目录索引，原始内置作物与旧版文件保留。现有作物包导出功能包含规范化状态图、Logo和完整配置。

删除会隐藏该植物的目录索引，原文件保留。当前/其他地图的种植、库存和田块归档仍引用植物时不允许删除；有这些引用时不能改变原有类型或总周期，避免存档失效。可先处理引用，或新增另一个植物编号。
