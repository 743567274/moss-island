# v2026.10.29 · 启动诊断与锁屏恢复

## 更新

- 监听 Windows 当前会话的锁定、解锁、桌面就绪、连接及断开通知。锁定时隐藏壁纸并暂停输入，解锁后等待桌面稳定，重新检查挂载与图层，恢复电源和可见性通知。
- 会话通知服务暂未就绪时持续尝试注册；休眠恢复也触发重新挂载。
- 渲染进程意外退出后最多自动重试两次，持续失败时保留托盘并提示诊断信息；长时间正常运行后的新故障使用新的重试预算。
- 托盘新增“重试启动壁纸”，可在渲染进程退出后手动重试。
- 启动异常、渲染输出与错误、退出码记录到 host/startup.log，避免启动失败只有窗口闪过而没有提示。

## 升级

从托盘“保存并退出”旧程序，再将新版完整解压至固定目录，运行 MossIsland.exe。不要直接启动 MossImmersive.exe，不要从压缩包内运行。更换程序目录后，重新配置开机自启。

右键托盘 → 解锁桌面后进行种植操作；完成后再锁定桌面。保留原有 Windows 用户存档，本版未更改存档格式与写入逻辑。

Windows 11 Insider 26300.9606 的单条版本信息不足以确定启动失败原因。若仍失败，请提供显卡型号、驱动版本、完整解压情况与实际启动的 EXE 名称，并提供以下日志：
