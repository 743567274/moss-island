# 地图编辑器使用说明

当前已升级为项目管理版：打开后先进入项目列表，新建项目完全空白。项目创建、复制、删除、独立种植存档及内置灯光请参见 [MAP-PROJECTS.md](MAP-PROJECTS.md)。

入口：桌面空白处右键 → 苔屿设置 → 地图编辑器。Windows 11 如果没有直接显示，可进入“显示更多选项”。托盘右键菜单也提供“地图编辑器 · 自定义素材”。桌面右键入口由启动器在当前用户下注册。

## 布置地图

1. 从画布点击或左侧列表选择田块、柳树、灯光或自定义装饰。
2. 拖动位置，或在右侧输入 X、Y；田块、柳树和装饰支持统一缩放。田块仍保持原来的正方形地面投影比例。
3. “保存草稿”只保存编辑结果；“应用到桌面”更新正在运行的壁纸，无需重挂载桌面窗口。
4. 支持撤销、重做和恢复初始布局。关闭未保存的编辑会提示是否丢弃。

1920×1080是编辑逻辑坐标，不是桌面显示分辨率限制。壁纸继续按实际显示器分辨率覆盖。

田块大小改变时，作物、接触阴影和点击区域同步跟随。田块编号绑定各自的种植存档，移动和缩放不会清空种植、修改库存或复制作物。支持从零添加、移除空田，最多128块，不改变作物配置中的单株数量和非种子1.3倍规则。

## 自定义素材

- 点击“导入图片素材”，支持PNG、JPG和WebP，透明PNG最适合树、草和建筑。
- 素材会复制为PNG存入农场数据目录，素材库会长期保存；原下载目录中的文件之后可移动。
- 在素材库选中图片，点击“添加选中素材到地图”，也可双击素材。
- 放置后可以移动、统一缩放、选择分类和启用随风摇曳。同一素材可多次摆放，实际文件按内容哈希去重。
- 移除装饰只移除这次摆放，不删除素材库原图。
- 建议导入时图片紧贴实际内容、根部靠近底部中央。树木、建筑等默认根部位于底部中央；土地、云、水和灯光的素材锚点默认居中。土地可另外设置种植锚点，不提供独立横纵缩放。
- 第一版单图最长边8192像素，地图最多128个自定义装饰；运行时使用缩小后的纹理，保留原图用于后续编辑。

树木分类使用叶片摇曳，草地分类使用根部固定的弯曲；云层使用缓慢漂移，水域使用局部贴图波动。灯光分类接入夜间局部光照，支持关闭闪动；当前地图共用最多4个光源。类型对应动画可以关闭。图片中的颜色和根部位置会影响效果。

## 素材类型与土地选中态

导入图片后会自动打开“素材属性”；也可以在素材库选中图片，点击“素材属性 · 类型与选中态”。类型与默认动画保存到`materials.json`，重新打开编辑器仍保留。

支持种植土地、地表/草地、树木/植被、云层、水域、建筑、装饰和灯光。程序按类型提供默认动画，用户可关闭；建筑、装饰和土地保持静止。

土地提供方形（菱形投影）、圆形/椭圆、图片透明轮廓三种点击范围；自定义轮廓使用透明通道，透明背景部分不能选中。轮廓选项不负责把普通矩形图片自动裁切成圆形，需要导入对应外观的土地图片。

选中态默认自动提亮，可调2%～35%，保留透明背景；也可以上传专用选中图，或切回自动效果。素材属性窗口同时显示正常和选中预览。壁纸运行时通过着色器生成提亮效果，不额外创建一张完整选中纹理；编辑画布仅缓存当前选中土地的预览。

在左侧指定“土地素材绑定到”哪一块田，再点击“添加选中素材到地图”。土地会替换该田的外观，已有位置、大小、作物和种植记录不变。选择“新增一块田”会创建真实田块；替换已有田块只改变外观，保留作物。

土地默认显示高度、种植锚点X/Y可以在素材属性调整，锚点范围0～1、默认均为0.5。换图时建议专用选中图与正常图采用相同画布和透明留白，防止选中时跳动。田块属性中可恢复默认土地贴图。

素材属性的修改影响以后放置的实例；已有土地需要重新绑定，同一素材的其他实例不会被悄悄改动。

## 昼夜预览

“夜景预览”便于布置，灯光圆点仅为位置标记。动画、光照与天气以应用后的桌面为准；本版编辑器是静态布局预览，不模拟完整桌面着色。

可以移动现有灯光，也可直接添加发散光、筒光、直射光，并调整范围、颜色、亮度、方向和夹角。

## 文件与存档

农场数据目录下新增：

```text
maps/
  active-layout.json      已应用的布局，下次启动自动加载
  draft-layout.json       编辑草稿
  materials.json          素材库索引
  materials/<hash>.png    导入的图片原件
```

布局JSON带版本号；替换前保存`.previous`副本，临时文件写入成功后才替换正式文件。布局与素材均存放在用户数据目录，重新构建程序不会覆盖。

迁移到其他电脑时复制整个`maps`目录；仅复制布局JSON不包含图片。本版尚无地图ZIP导入导出。

编辑器关闭后释放预览图片和窗口，避免长期增加壁纸内存占用。

## 第一版边界

房屋、桥、河岸、远山、草地以及部分树仍绘制在底图里，无法逐个拖动；独立柳树和田块可以编辑。自定义素材会叠加在背景上，不会自动修补被移动对象原来的背景。本版支持自定义装饰之间按根部纵向排序，尚无完整的桥下遮挡或前后景分层工具。

地图级不可见水域绘制、分类素材与统一图层已加入，操作见 `MAP-CLASSIFIED-EDITOR.md`。地图包导入导出尚未加入。

按本次约定未运行功能或性能测试；构建时跳过测试。
