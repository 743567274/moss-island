# 玉米配置与作物包

本版按用户要求清除旧作物、柑橘与库存，只保留玉米，18 块田统一种植。旧数据在升级前另行备份；v5 → v6 只清空一次，新种植重启后继续保留。作物使用真实经过的秒数，离线继续生长、耗水，不再提供加速或暂停。

## 从哪里调整

运行版本编辑 `build/crops/corn/crop.json`，保存后重启。开发版本编辑 `data/crops/corn/crop.json`。打包会将开发配置复制到运行目录，重新打包前请把希望保留的运行配置改动同步回开发配置。

每张素材仅有一个等比例缩放参数。例如：

```json
"adult": {
  "file": "adult.png",
  "scale": 1.0,
  "region": [0.1, 0.1, 0.8, 0.8]
}
```

示例 `region` 仅说明结构，以实际文件为准；它记录原图透明留白之外的有效区域，通常无需调整。改 `scale` 即可：`0.8` 缩小到 80%，`1.2` 放大到 120%，宽高同步变化，根部留在原田块位置。没有横向、纵向独立缩放项。`icon.scale` 同样作用于仓库图标。

| 配置素材 ID | 用户原图 | 用途 |

| seed | 种子.png | 播种 |
| seed_dead | 种子枯死.png | 种子缺水死亡 |
| seedling | 幼苗.png | 幼苗 |
| seedling_dry | 幼苗缺水.png | 幼苗缺水 |
| seedling_dead | 幼苗死亡.png | 幼苗死亡 |
| juvenile | 半成熟.png | 半成熟 |
| adult | 长大.png | 成株 |
| adult_dry | 收获完-长大缺水.png | 成株缺水 |
| fruiting | 结果.png | 结果灌浆 |
| mature | 成熟.png | 可以采收 |
| residue | 长大枯萎.png | 成株死亡、采收后枯株 |

12 张图片按原字节复制，不覆盖用户原文件。渲染使用有效区域、等比例缩放和 mipmap 缩小过滤，避免大图缩小出现闪烁锯齿。

## 生长与水分

| 阶段 | 健康供水下本阶段时长 | 进入阶段的累计时间 | 储水消耗 mm/天 | 储水完全耗尽后连续多久死亡 |
|---|---:|---:|---:|---:|
| 种子 | 7 天 | 0 天 | 1.5 | 3 天 |
| 幼苗 | 14 天 | 7 天 | 2.5 | 5 天 |
| 半成熟 | 21 天 | 21 天 | 3.5 | 7 天 |
| 长大 | 18 天 | 42 天 | 5 | 7 天 |
| 结果 | 60 天 | 60 天 | 6 | 7 天 |
| 成熟 | 等待采收 | 120 天 | 0 | 不因缺水再次死亡 |

`stages[].seconds` 为本阶段时长，1 天 = 86400 秒；最后成熟阶段为 0 秒并设置 `harvestable: true`。所有阶段时长总和必须等于 `duration`。成熟后收获保留 `harvest.residue_sprite`，需要先清理枯株才能再播种，每块田只能收获一次。

默认土壤储水上限 40 mm，播种初始储水 0，需要及时浇水。每次浇水加 30 mm，最多达到上限；低于 10 mm 提示缺水，低于 2 mm 暂停成长，储水为零后累计连续旱情，超过阶段阈值死亡。及时浇水可恢复尚未死亡的植株，死亡不能复活。界面预计成熟时间以之后正常供水为前提。

上述水分容量、初始水量、每次补水量、警戒线、生长最低线、干旱生长倍率、每阶段日耗水、连续干旱死亡阈值均在配置中。不是每隔几小时强制浇一次水，而是按土壤存水量计算下一次补水时间。

仅新鲜真实天气的短在线结算区间按雨档补水；环境测试的雨雪不影响作物，离线期间不推测历史降雨，缓存过期或关闭联网后也不补雨水。`rain_mm_per_hour`、吸收率及有效观测区间上限可配置。雪不作为灌溉来源。

默认每块田按 2×2 排列 4 株，一次收获 4 穗，见 `harvest.yield` 和 `harvest.unit`。仓库采用格子，右下角显示收获数量。

## 农艺依据与适用范围

本配置采用中熟籽粒玉米约 120 天的参考周期，结果阶段取 60 天；[明尼苏达大学玉米生长指南](https://extension.umn.edu/agriculture/crop-production/corn/growth-and-development)说明吐丝后约 55—65 天达到生理成熟。[灌溉管理资料](https://extension.umn.edu/natural-resources/conservation/agricultural-soil-and-water/irrigation/irrigation-management-strategies)说明需水随生育期变化。

不同品种、土壤、温度及种植条件并没有统一的逐阶段日数或固定“断水几天必死”规则。阶段拆分、默认储水及死亡阈值是可调的模拟标定；当前并非基于历史逐小时气象、土壤检测和积温的完整农学模型，温度天气预览不会改变这些时长。

## 导出与复用

托盘 → 仓库 → 导出玉米作物包，选择 ZIP 保存位置。包含 `crop.json` 和全部 12 张 PNG，不包含电脑绝对路径。种植、收获、水分、状态素材、等比例缩放、排布和图标参数随配置一起导出。

解压后可将内容放到另一份程序旁的 `crops/corn/` 下重启使用。本版只启用玉米，暂未提供任意新物种的安装界面。预先生成的包为 `build/玉米.crop.zip`。导出采用临时文件完成后替换，失败时保留已有包。

外部配置格式有误会记录诊断并回退到内置玉米包，避免运行崩溃。配置中素材必须是同目录 PNG；禁止路径跳转。缩放范围为大于 0、至多 10。
