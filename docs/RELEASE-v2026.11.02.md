# v2026.11.02 · 作物铲除与确认提示

- 有作物的田块现在也可以使用铲子，不再仅允许收获成熟作物或清理残株。
- 种子、幼苗、缺水等仍存活的作物，铲除前会显示确认提示，明确不会获得收获物。
- 成熟作物的提示框同时提供“收获”和“确认铲除”，由用户决定。
- 枯死作物与采收后残株仍可直接清理。
- 确认时核对原田块与作物对象；切换地图、田块或锁定桌面后，不会将待确认操作应用到其他作物。
