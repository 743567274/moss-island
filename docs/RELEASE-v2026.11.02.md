# v2026.11.02 · 作物铲除与确认提示

## 更新

- 修复有活作物时铲子不可用的问题。种子、幼苗、半成熟以及缺水中的活作物都可以铲除。
- 铲除活作物前显示确认提示，说明清空作物且不获得收获物；取消不会清理作物。
- 成熟作物提供“收获”和“确认铲除”选项，保留正常采收。
- 已枯死作物、采收后的残株可直接清理。
- 确认时重新核对原农场、田块对象和当前选择；切换田块或地图后，不会把待确认操作转移到其他作物。

## 使用与升级

先从托盘“保存并退出”旧版本，再完整解压新版，运行 MossIsland.exe。不要只替换单个 EXE。
右键托盘 → 解锁桌面 → 选中田块 → 点击铲子。操作完成后可右键托盘锁定桌面。
本版沿用现有存档格式与个人用户数据。开机自启目录变更后需重新设置。
