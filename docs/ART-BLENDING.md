# 土地与作物的画面融合

保留现有原始图片与种植规则，在既有土地和植物着色器内增加融合效果，不增加根部模型、灯光或额外绘制图层。柳树第二版及其独立着色保持原配置。

## 土地与根部

田块外围依据菱形边缘和固定噪声，局部混入背景草地的实际颜色，避免规则而锋利的土块轮廓；选择状态减弱这一混合并略提亮土地，保留辨识度。白天与夜晚分别取对应背景，仍参与天气、月光和雾的变化。

每株位置产生一个小范围柔和接触阴影，全部田块均可使用。阴影强度不随植株随机大小跳变，种子阶段减弱。空田块、铲除后清空对应阴影。

非种子植株的底部局部混入土色，并用两片很短的草叶遮挡根脚，帮助根部衔接土壤；这些细节在原有精灵平面内计算，不创建新节点。种子阶段不开启草叶遮挡。

## 颜色、线条和四株差异

作物轻微降低饱和度和线条反差，以现有mipmap采样略柔化过细的纹理，再增加很弱、固定于世界坐标的颗粒变化。不会只靠整体压暗来融合，仍使用之前的中性日间照明及夜间月光照明。

每块田默认1株并居中，非种子阶段统一放大30%，种子与种子枯死图保持原大小。单株时关闭株间随机大小差异；若以后配置多株，可继续使用±3.5%的大小差异。亮度差和风摆相位保留固定的田块种子；变换围绕根部锚点缩放，避免根部漂移。没有逐帧CPU随机运算。

## 参数

每个作物的 `crop.json` → `render` 中，`columns=1`、`rows=1` 表示每田一株，`non_seed_scale=1.3` 表示非种子阶段统一放大30%；与单张素材的 `assets.<状态>.scale` 相乘，不改变仓库Logo大小。

`render.art_blending`：

| 参数 | 默认 | 用途 |
| --- | --- | --- |
| style_saturation | 0.90 | 饱和度；1保留原饱和度 |
| style_contrast | 0.94 | 线条反差；1保留原反差 |
| texture_softness | 0.22 | mipmap采样偏置；0不额外柔化 |
| paper_grain | 0.012 | 细微纹理强度；0关闭 |
| phase_variation | 0.70 | 每株风摆相位差的总范围，弧度 |
| root_detail | 0.70 | 根部土色与草叶遮挡强度；0关闭 |
| size_variation | 0.035 | 大小变化上限；0完全等大 |
| wind_response | 4.8 | 风力响应放大系数；0关闭风摆，上限10 |

单张素材的 `assets.<状态>.scale` 仍有效，与这里的轻微株间差异叠加。所有作物包的导出配置都包含这些参数。

地图 `data/lakeside-map.json` → `art_blending`：

| 参数 | 默认 | 用途 |
| --- | --- | --- |
| edge_grass | 0.64 | 田边与背景草色过渡强度 |
| root_shadow_strength | 0.17 | 根部接触阴影强度 |
| soil_saturation | 0.92 | 土地饱和度 |
| soil_contrast | 0.94 | 土地纹理反差 |
| paper_grain | 0.012 | 土地细微纹理强度 |

## 性能与发布

复用场景已加载的背景与土地纹理，不增加专用大图。每田仍使用一个 MultiMesh 绘制作物，单株尺寸和相位通过[Godot MultiMesh 自定义数据](https://docs.godotengine.org/en/stable/classes/class_multimesh.html)传递；每株额外16字节自定义数据及少量根部参数。没有新增实时阴影贴图或全屏后处理。

着色器增加了少量运算与局部纹理采样，实际GPU变化尚未测量，不保证零开销。按用户要求，仅构建与重启，没有运行测试或性能测试；最终观感需在桌面确认。原存档、作物生命周期、温度和浇水参数不变。

## 风摆可见度修正

原来的风摆只有很小的UV位移，小植株投影到桌面后往往不足一个像素；风向投影还存在抵消角度。现在作物使用根部锚定的分段平面弯曲，摆幅按植株高度计算，避免窄小植物的风摆看不出来。仍沿用每田一个MultiMesh，不增加逐帧CPU动画；平面增加少量纵向细分。

柳树仍只扭动叶片，不弯曲树干。垂叶末梢的遮罩不再过早衰减，并通过地图的 `willow.wind_response`（默认6）调整响应。所有风向采用二维投影，避免相加抵消。强风下加入轻微的高频摆动分量，静风保持不动。

精灵平面增加6%的四周透明活动余量，原始树形尺寸与根部位置保持一致，减少风摆时叶片在图像边缘被裁断的情况。种子仍由 `seed_sway` 控制，默认不摆。
