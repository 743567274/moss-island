# 植物类型、温度与风

所有植物仍以独立作物包存放：`crops/<id>/crop.json`，配置和原始图片一起导出。旧包没有新增字段时仍可读取；当前玉米、棉花已补全类型和温度配置。

## 类型

- `type: "crop"`：播种 → 生长 → 成熟 → 采收 → 枯株 → 铲除。`harvest.repeatable` 必须为 false。
- `type: "fruit_tree"`：种下树苗 → 长大 → 结果成熟 → 收获 → 再次结果。首个阶段不能叫 `seed`，所有阶段都使用 `render.sway` 随风摆动。`harvest.repeatable` 必须为 true，`harvest.regrow_stage` 指向一个非最终阶段的 `id`，例如 `fruiting`。收获保留树、土壤水分及温度伤害，只把生长进度退回该阶段起点；再次经过该阶段到成熟阶段即能再收获。每次采收按 `harvest.yield` 入库，不产生作物的采后枯株。

果树配置依然提供 `residue_sprite/residue_height`，用于保持包结构兼容，但循环收获不会用到它们。类型机制已经接入，尚未添加具体果树或占用地块。所有生长阶段都需唯一 `id`，所有真实种子阶段使用 `id: "seed"`；果树从树苗开始，不能包含种子阶段。

新增果树包放在 `data/crops/<id>/`，将其配置路径登记到 `data/catalog.json` 后重新构建，即会自动出现在背包、仓库、导出选择及阶段预览中。发布后可编辑程序旁对应的外置配置。

## 温度

```json
"temperature": {
  "min_c": 15.6,
  "max_c": 35,
  "sowing_min_c": 18,
  "sowing_max_c": 32,
  "unsuitable_growth_factor": 0,
  "stress_death_seconds": 129600,
  "recovery_per_second": 2
}
```

以上为棉花默认配置。`min_c/max_c` 是生长适宜范围，`sowing_min_c/sowing_max_c` 是种子阶段范围。播种时若有有效天气且温度不适，立即显示温度萎蔫。之后只在有效观测覆盖的时间段内累计伤害；不适时成长乘以 `unsuitable_growth_factor`，0为暂停。持续伤害累计达到 `stress_death_seconds` 时死亡；适温时每秒恢复 `recovery_per_second` 秒伤害。水分单独结算，浇水不会消除温度萎蔫。

玉米默认生长10–35°C、播种10–32°C，不适温度累计48小时枯死；棉花默认生长15.6–35°C、播种18–32°C，累计36小时枯死。温度回到适宜区间后，下次结算解除温度萎蔫，伤害逐步恢复；死亡不能恢复。天气关闭、无数据、缓存过期或无历史数据的离线区间不凭空推算温害。显示的“周期”是适温、正常供水的日历参考周期。

气象接口提供空气温度，并非地块实测土温。本项目使用它近似温度条件；适宜区间、暂停策略和死亡时间均为游戏模拟参数，不能当作普适农艺判断。参考[玉米生长资料](https://extension.umn.edu/agriculture/crop-production/corn/growth-and-development)和[棉花建植资料](https://www.cotton.org/tech/ace/establishing-the-crop.cfm)，实际生长还受积温、品种、土壤和气候影响。

## 展示与风

田块信息直接显示适宜生长温度、参考周期；悬停信息显示播种温度、产量、类型等详细参数。仓库点击物品格子可查看同样详情，果树另显示再次结果周期。

天气请求明确采用 km/h 获取10米风速和风向，缓存保存原始值。风力逐渐过渡，增强河流波纹、柳树树叶、种植植物和雨雪偏移；树干和根部保持锚定。真实种子使用 `seed_sway`，其他阶段使用 `sway`，果树从种下起就使用 `sway`。风动画在着色器中计算，不新增逐株CPU动画。

接口字段参见 [Open-Meteo 文档](https://open-meteo.com/en/docs)。

## 透明贴图与颜色

原始透明PNG与导出图集保持原样。`render.edge_cleanup` 可针对存在抠图白边的素材开启运行时清理：`radius` 为源图像素范围（1—6），`light_min` 为浅色下限，`alpha_max` 为处理透明度上限，`saturation_max` 为RGB最大最小通道差上限（后三者0—1）。当前棉花使用3、0.68、0.94、0.28。仅处理靠近透明区的浅色半透明像素，不按白色全图抠除；正常棉絮和金色选择边尽量保留。没有白边的素材可省略此字典。

运行时加载会补全透明区边缘颜色，再缩小及生成mipmap，避免透明像素的背景色污染缩小时的颜色。缓存使用v2目录，旧缓存不会被继续读取。植物白天使用接近原图的中性照明，阴天略压暗；原图已有的叶片明暗不再叠加虚构曲面阴影，夜间仍受月光和局部灯光影响。土地清理参数单独位于地图的 `soil_edge_cleanup`。
