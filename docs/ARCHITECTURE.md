# 2.1.0 种植版架构

MossIsland.exe 为 C# 托盘控制中心；任一时刻仅运行一个 Godot 渲染器写存档。DesktopBridge.exe 负责 WorkerW 挂接、输入转发、图标排除、电源与遮挡状态。沉浸锁定/解锁仅切换输入，不反复重设父窗口。陪伴模式透明穿透，移动结束后恢复穿透。

FarmState v4 只包含作物、田地、时间、种植设置、装饰与作物收藏；ContentCatalog 只加载作物目录。SaveManager 的 v1→v2→v3→v4 兼容转换保留 ID 与作物状态，移除退休字段。SHA-256、原子保存、三份备份和独立收藏存储保留；收藏合并只接收作物记录。

Diorama / Courtyard 已移除牧场、鱼塘构建、生物模型、成长缩放和逐帧动画。12 个 plot_position 保持不变。内部镜头为全景、田畦、庭院三个，场景只对田畦提供交互。主 UI 为右上角全景按钮和右侧上下文面板；设置、收藏、环境测试采用独立窗口。

外围湖景保持背景用途，和已移除的内塘区分。贴图采用 BC7 与有限尺寸导入，环境树石按源模型/材质和空间分组为 MultiMesh。船和莲以装饰模型使用，采用已有的压缩贴图。右岸草地轮廓形成荷湾，独立水面低于草地、高于陪伴剖面；陪伴模式保留荷湾，外围湖景仍移除。18 片曲面荷叶使用一个 MultiMesh，草叶静态合批。荷湾没有命中区域、计时器、成长或产出状态，存档仍为纯作物 v4。农舍比例 .70→.96，移除院墙。

PerformanceManager Compatibility/OpenGL，均衡 85%、高画质 100% + 2×MSAA、锁定 10 FPS；后台节能开启时按桌面桥接的覆盖状态暂停渲染，逻辑结算继续。恢复时同步真实环境。天气和临时环境预览独立，测试时刻、气温不会写入真实生长。

V2 渲染：Courtyard 以程序化网格构建统一风格，静态网格按角色合并；顶点颜色烘焙基础明暗，共享四类笔触材质。EnvironmentController 保存大气目标与当前值，按真实经过时间平滑变化、润湿/干燥与积雪/融化。CPU 不逐粒子执行碰撞，雨雪 MultiMesh 初始位置与承接高度预先采样，GPU 按时间计算轨迹。水面涟漪为解析函数，地面落点为批量环形片。旧 assets/reference 不加载也不导出。天气服务缓存附加云量、降水、风速、风向，缺字段时继续兼容原码值/气温缓存；云量、风速与风向影响渐变参数、植被摆动和雨雪漂移。

2.1.0 主场景使用 PaintedCourtyard（继承 Courtyard），覆盖农舍、屋瓦曲面、树、土畦和白菜/胡萝卜建模；基础环境/水/生长协议沿用。SurfaceTool 生成独立 UV，合批时为 authored_uv 节点保留 UV，其他旧几何继续世界投影。八分区图集、三张在线手绘纹理、透明叶簇均设置 1024 上限、VRAM 压缩和 Mipmap。每株树 20 个 Multimesh 叶片卡，alpha scissor 把透明背景裁掉，保留真实 3D 树干与多方向叶片体积；不是一张整树贴片。

沉浸正式程序继续 Mobile/Vulkan、陪伴 ANGLE/D3D11；Win11 raised desktop 的 Progman 层级修复保留。陪伴模式移动结束后等窗口事件稳定再确认 companion，500ms 低频检查只在 Godot 覆盖 EXSTYLE 时修正穿透位，不重设父窗口和帧缓冲。

## 2.2.0 当前渲染架构

入口改用 IllustratedCourtyard extends Courtyard，只复用环境控制与主机契约，不构建旧三维房屋/岛屿几何。ReferenceLayout 将用户效果图坐标映射为固定俯视正交平面：12 个菜地和 6 个果位的可见位置与命中采用同一份布局。reference_plate.gdshader 在局部种植区域合成空底，其他静态像素仍采样原图；精灵使用原图同风格的透明阶段素材。陪伴按需加载独立透明前景，沉浸不加载它。

FarmState v5 在原有菜地数据旁增加 orchard，SaveManager 安全迁移 v4。果树按真实时间结算并在成熟时封顶，采收退回开花阶段。视觉阶段变化才重建精灵；预览阶段使用独立 tree_preview，不修改存档。EnvironmentController 保留雨雪渐变，但 snow/ice 固定为 0；雪仅作为下落粒子。固定画面无需实时网格阴影、三维雾或动物逻辑。

## 2.3.0 地图模块与原生陪伴表面

MapDefinition 读取独立 JSON，ReferenceLayout、田块网格、植物根部与点击命中共用坐标。底图已移除烘焙的旧田块，18 个土地模块独立绘制，选择只改变所属土壤材质。河流路径、桥面排除区、最多四盏灯由地图配置驱动；天气保持独立。静态绘制为 1 张底图加 18 个土块，另有植物及天气批次，不能再按 2.2.0 宣称只有一个静态绘制。

沉浸壁纸仍走原有 Mobile/Vulkan 与 Progman 图标下层级。陪伴模式隐藏 Godot 的 GPU 窗口，将渲染上限设为 10 FPS，每 0.2 秒读取一次小尺寸 RGBA 视口，经原子 PNG 文件传给 DesktopBridge。CompanionOverlay 用 UpdateLayeredWindow 提交逐像素 alpha，窗口带 TOOLWINDOW/NOACTIVATE/TRANSPARENT、不带 APPWINDOW，不占任务栏。移动时临时取消穿透，位置写回同一份偏好设置。原生层仅显示图像，不读写农场逻辑。此路径会增加低频截图/PNG 编解码开销，不能承诺其 CPU 低于原有 GPU 透明窗口；需以实际采样为准。

## 2.4.0 DPI、素材田块与分层光照

DesktopBridge 在创建任何窗口之前调用 SetProcessDpiAwarenessContext(-4)，再设置线程 Per-Monitor V2。修复仅设置 System DPI Aware 后得到 1920×1080 虚拟尺寸的问题，实际物理显示器为 2560×1440。每秒检查显示器边界变化，仅在尺寸或位置变化时调整挂载窗口；稳定锁定/解锁不改父窗口或尺寸。`--display-report` 可对照 GetMonitorInfo 和 EnumDisplaySettings 的物理尺寸。

方形土地改用去背景后的普通/选中透明图片，按有效 alpha 包围框对齐，显示矩形的尺寸来自方形投影的包围框；点击坐标保持同一格基底。garden_lighting.gdshaderinc 给土地和植物添加方向明暗、柔和树影和局部灯光溢色。背景在白天图层和独立月夜受光图层间平滑融合，月光强度继续读取真实月相。月夜图中的静态受光方向为手绘设计，动态植物为近似受光，不是完整三维光线追踪。

环境预览立即收敛到目标，真实天气仍渐变。雨恢复细雨丝，三档大小/密度变化、固定落速。雪保留原轨迹与风摆，仅改变大小/密度。涟漪 shader 对每个实例的每轮生命周期重新计算随机落点，水域点仍落在河道路径附近，地面点保持屏幕下方三分之二。退休的雷暴天气码与旧自定义 storm 效果统一作为普通降雨处理。
